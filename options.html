Create the repo on GitHub first if it doesn’t exist. If you delete a solution’s folder on GitHub, click Forget problems deleted from repo so SolveSync will push it again.

Repository layout

Tokens: {platform} {group} {difficulty} {id} {slug}. {group} is the primary topic on LeetCode, the rating on Codeforces, the section on CSES and the contest type on AtCoder. Default gives LeetCode/array/0001-two-sum/solution.py with a README.md beside it.

Platforms & usernames

A solution is only pushed when it was submitted from the username saved here. Submissions from any other account are ignored. Leave a platform unchecked to skip it entirely.
